# Formação Data Engineer

> Repositório de anotações e exercícios práticos da formação Data Engineer da DataEngineer.help.

O objetivo é organizar, de forma progressiva, o estudo das principais ferramentas e conceitos da área de dados, indo além da formação acadêmica e construindo uma base prática para atuação profissional.

Ao longo da formação, a ideia é consolidar fundamentos de programação, manipulação e análise de dados, SQL, automação e engenharia moderna de dados, além de desenvolver projetos práticos que possam compor um portfólio consistente.

## Como o conteúdo é organizado

- Trilhas: agrupam os temas principais da formação.
- Módulos: subdividem cada trilha em blocos de aprendizado.
- Anotações: registram conceitos, comandos, boas práticas e dúvidas importantes de cada tópico.
- Exercícios: guardam resoluções, testes práticos e pequenas entregas para fixação.
